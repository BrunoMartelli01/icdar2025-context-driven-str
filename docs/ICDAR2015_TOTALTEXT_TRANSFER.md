# ICDAR2015 U-Net and word-mask transfer from Total-Text

This is an **approximate reproduction**, authorized as an ICDAR2015 improvement
experiment. The inspected sources are local paper `papers/2503.15639v2.pdf`,
section 3.2/Figure 3 and section 4.1; `models/unet_adv.py`;
`segmentation/scene_text_preparation.py`; the Total-Text word-region,
high-resolution, image-frequency and word-F1 experiments. It does not establish
new paper Table 3/5 results. ICDAR2015 segmentation training itself is an
extension: the paper lists ICDAR2015 as a recognition benchmark.

## Comparison and selected changes

| Component | Existing ICDAR2015 configuration | New isolated transfer |
| --- | --- | --- |
| Input and native logits | 256 RGB / 128 mask | 512 RGB / 256 mask |
| Image geometry | Square stretch | Paired aspect-preserving letterbox |
| TRAIN masks | Union of filled word quadrilaterals | Same quadrilaterals with disjoint ownership, contact and short-gap separators |
| Attention skip multiplier | Sigmoid attention | `0.25 + 0.75 * attention` |
| BCE | Valid-pixel BCE | Same BCE, separator pixels weighted 3 |
| Encoder | Frozen ImageNet ResNet-50 V2, frozen BN | Same, loaded from an explicit checksum-pinned checkpoint |
| Decoder | Author-clarified 1024 bottleneck, 512/256/128/64 stages | Reused operations, independent architecture identity, single output |
| Population and checkpoint selection | All 1000 TRAIN; training foreground IoU | Frozen 900/100 TRAIN split; validation word-proposal F1 and declared tie breaks |

The original Total-Text pixel masks and its newer filled word-region masks
have different semantics. ICDAR2015 provides word quadrilaterals, not the pixel
GT seeds used by Total-Text's v4 curved fitting. This transfer therefore keeps
the original ICDAR quadrilateral geometry and reuses only ownership,
separation, paired transforms and the selected U-Net operations. It does not
invent glyph masks, use curved fitting, or load Total-Text model weights.

The saved Total-Text high-resolution comparison on 125 held-out TRAIN images /
983 words reports 326 words with a proposal bbox IoU >= 0.5 for its baseline,
and 423 with the combined separator-loss/residual-attention variant. Words
touched by fused components decline from 554 to 476. These are historical
topology diagnostics, not one-to-one recognition accuracy or proof of an
ICDAR2015 gain. Source report SHA256 identities are frozen in
`configs/approximate/icdar2015_totaltext_transfer_v1.json`.

The newer matched word-F1 Total-Text control has proposal F1 0.520704; its
additional separator-head arm has 0.488665. The saved PARSeq diagnostic has
384/983 exact spatial matches for the control and 362/983 for that head.
Consequently the extra prediction head is not transferred. Letterbox is reused
as the qualified aspect-preserving geometry; previous unequal-budget input
ablations do not establish an isolated causal improvement.

## Validation and scientific boundaries

The new model is `models/icdar2015_unet.py`; shared historical implementations
and STRICT/demo configurations are preserved. The new approximate config is
explicitly selected and cannot be loaded from a strict/demo directory.

Only official TRAIN enters training or validation. Validation assignment ranks
`SHA256(202503:sample_id)` and freezes 100 IDs. IDs, image paths and RGB hashes
must be disjoint. No checkpoint trained on all 1000 images is used to initialize
the decoder: that would leak the held-out population.

Selection maximizes native one-to-one bbox proposal F1 at IoU >= 0.5, then
minimizes words touched by fused components, then maximizes recall and macro
valid-pixel foreground IoU, then chooses the earliest epoch. This is a local
geometry proxy, not official ICDAR polygon Hmean, OCR accuracy or paper Table 3.
Sigmoid cutoff stays 0.5. Every 8-connected proposal counts; no area/top-ten
filter or padding is applied in this diagnostic. Prediction clipping uses only
the RGB-derived letterbox canvas; ignored-region predictions still count.
GT validity excludes ignored pixels from BCE/pixel IoU and removes ignored GT
owners. Lost GT words remain in all word denominators. Empty pixel unions
score 1; precision/recall with empty denominators score 0.

Resolved configuration, source hashes, split IDs, seeds, model/optimizer/RNG,
checkpoint hashes and runtime metadata are saved. Best and latest checkpoints
are distinct. Exact-contract `--resume` verifies completed results or restores
the latest epoch; source/configuration changes cause failure. Interruption
between best/latest writes may require manual inspection and fails explicitly.
Selected validation probabilities, predictions, targets, validity, owners and
expected word IDs are saved per image with SHA256 identities.

## Reproducible commands on PAPER

Use the existing main environment; no installation is required. Preparation
refuses an existing output directory. Do not rerun it over the qualified data.

```bash
.venvs/context-str-main-py311/bin/python -m scripts.prepare_icdar2015_word_regions \
  --config configs/approximate/icdar2015_totaltext_transfer_v1.json \
  --source-root /extra1/bmartelli/datasets/context-str/scene-segmentation-v1 \
  --output-root /path/to/new/icdar2015-word-regions
```

Check actual GPU availability first. Full training (100 epochs, 900 TRAIN /
100 validation) uses a new output directory:

```bash
OMP_NUM_THREADS=4 MKL_NUM_THREADS=4 CUBLAS_WORKSPACE_CONFIG=:4096:8 \
.venvs/context-str-main-py311/bin/python -m scripts.train_icdar2015_totaltext_transfer \
  --config configs/approximate/icdar2015_totaltext_transfer_v1.json \
  --data-root /extra1/bmartelli/datasets/context-str/icdar2015-word-regions-totaltext-transfer-v1 \
  --encoder-checkpoint /extra1/bmartelli/.cache/torch/hub/checkpoints/resnet50-11ad3fa6.pth \
  --output-dir /extra1/bmartelli/context-str-runs/icdar2015-totaltext-transfer-v1-train \
  --device cuda:0
```

Add `--smoke-steps 2` with a different output directory for a single partial
epoch (16 training and up to 16 validation images). It is labeled `smoke-test
result` with `training_complete=false`, even though the configured budget is
100 epochs. Add `--resume` only for that exact existing run. The initial
implementation qualification below did not include full training. The later
user-authorized 100-epoch training and TEST500 word-F1 evaluation are complete;
see [ICDAR2015_WORD_F1.md](ICDAR2015_WORD_F1.md). A matched original-model
comparison establishing improved accuracy remains `UNRESOLVED`.
